# Audit RADAR — 2026-08-09

Audit factuel (métriques mesurées, pas d'impressions). Volumétrie : 23 pages ·
227 composants · 56 hooks · 50 edge functions · 86 migrations · 19 fichiers de test.

## Verdict global

Produit **sain et honnête** sur le fond (crédibilité, architecture éditoriale
en place), mais qui porte une **dette de typage** importante et quelques points
d'hygiène. Rien de bloquant en production ; deux points sécurité/perf méritent
un tour.

Cotation : 🟢 bon · 🟡 à surveiller · 🔴 à corriger.

## 1. Sécurité — 🟢 (1 point 🟡)

- 🟢 **Aucun secret en dur** côté front ; **aucune fuite de `service_role`**.
  Clés via `import.meta.env` uniquement.
- 🟢 Rate-limiting sur reset-password / magic-link (fait, #82).
- 🟢 **XSS — corrigé.** `MatinalePage` sanitise désormais l'aperçu via DOMPurify
  (même config que le Newsletter Studio). Plus aucune injection HTML non nettoyée
  dans le produit.
- ⚪ Advisors Supabase (RLS, policies) **non vérifiables** ici : le jeton MCP n'a
  pas la permission. À lancer depuis un compte owner (`get_advisors security`).

## 2. Qualité du code / dette — 🟡

- 🔴 **Lint : 344 problèmes** (320 erreurs). Dont **302 `no-explicit-any`** —
  c'est LE gros morceau : 69 `as any` + des `any` implicites. Non bloquant
  (build OK) mais érode la sûreté de type et masque des bugs.
- 🟡 **8 `react-hooks/exhaustive-deps`** — risques de closures périmées, dont
  deux sensibles : `useRealtimeAlerts.ts` et `AlertNotificationProvider.tsx`
  (temps réel → un dep manquant peut figer les alertes).
- 🟡 **4 `catch {}` vides** (`no-empty`) — avalent des erreurs en silence.
- 🟢 `@ts-ignore` : 1 seul. `Math.random` fabriqué : **0** (garde CI active).
- 🟢 4 TODO/FIXME, 4 `console.log` résiduels — négligeable.

## 3. Crédibilité — 🟢

- 🟢 Surface produit (8 écrans DIRCOM) **exempte de métriques IA non vérifiées**
  (audit #56).
- 🟢 **Garde anti-régression en CI** : `Math.random` interdit dans un composant
  affiché (`credibiliteGuard.test.ts`).
- 🟢 Chartes permanentes : crédibilité, couleur, navigation, architecture
  éditoriale — toutes documentées et appliquées.
